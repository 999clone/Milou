# 📧 Milou  
*A simple yet powerful email management system built with Java & Hibernate.*  

## ✨ Features  
Milou gives you all the essential tools to manage your emails in one place:  
- 📥 **Inbox** – View received emails  
- 🔔 **Unread Filter** – See which messages you haven’t opened yet  
- ✅ **Mark as Read** – Mark emails as read once you’ve seen them  
- ↩️ **Reply** – Send replies directly to any email  
- 🔀 **Forward** – Forward emails to other recipients  
- 👥 **Recipients** – Add and manage recipients for each email  
- 🔑 **User Accounts** – Secure login & user management  

## 🖥️ How It Works  
1. **Login / Sign up** with your email and password  
2. **Send an email** to another user in the system  
3. **Receive emails** in your inbox  
4. **Open unread emails**, reply, or forward them  
5. **Check sent items** to keep track of what you’ve shared  

## 📂 Project Overview  
- **Core Entities**: `User`, `Email`, `Recipient`
- **Email Actions**: Reply, Forward, Mark as Read
- **Architecture**: DAO pattern+ Hibernate utilities
